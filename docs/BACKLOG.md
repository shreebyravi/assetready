# AssetReady: Backlog (next scope)

| # | Story | Acceptance criteria |
|---|---|---|
| B1 | As a handover manager, I upload the contractor's PDFs and spreadsheets so I don't retype anything | PDF and XLSX parsed; every extracted fact keeps file, page or cell; unreadable pages listed |
| B2 | As a handover manager, I see the exact page a quote came from | Clicking evidence opens the PDF page with the text highlighted |
| B3 | As a handover manager, I can trust that each asset was checked more than once | Each asset run at least twice; disagreements flagged for review |
| B4 | As an FM operations manager, I must approve any life-safety asset | Life-safety assets need a second approver; recorded in the audit trail |
| B5 | As a handover manager, I export the request letter per contractor | One document per responsible party, grouped by asset, with evidence references |
| B6 | As a CAFM administrator, I get a corrected register to import | Export with only approved corrections; original values kept alongside |
| B7 | As a client, I set my own readiness rules | Rules editable per project; changes versioned and shown on every result |
| B8 | As a team, we keep one audit trail | Decisions stored on a server with user, time and reason; no browser-only state |
| B9 | As a handover manager, I see defects and snags next to assets | Open snags linked to assets and counted in readiness |
| B10 | As a product team, we monitor quality in use | Weekly sample review; quote-check failures, tool errors and run disagreement tracked |
